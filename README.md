# 任职管理系统

PHP 8.1+ 与 SQLite 实现，管理端采用 A「深海行政」视觉风格，包含岗位、预登记、人才审核、面试安排以及应聘/面试 H5 流程。

## 已实现模块

- 管理端登录、工作台、用户管理
- 岗位管理与岗位应聘入口
- 综合测评结构化评分标准及版本发布
- 通用题库、岗位专业题库与题卷版本发布
- 应聘者预登记及 CSV 导出
- 手机号与岗位双重验证、在线答题和自动计分
- 初审、终审、人才数据 CSV 导出
- 面试场次、候选人和多面试官配置
- 面试官姓名验证、独立评分和防重复提交
- 关键业务操作日志
- 数据驱动的在线题卷与题目快照
- 单选、多选客观题自动判分
- 简答题人工评分与综合分重新计算
- 文本批量预登记（姓名、手机号逐行导入）
- 管理员创建内部用户与角色
- 结构化评分规则解释器及维度得分明细
- 已发布题卷优先加载与历史题目快照
- 多面试官权重汇总及面试结果页
- 当前用户安全修改密码
- 岗位编辑、应聘入口令牌轮换
- 候选人取消预登记与答题前改岗
- 题目启停与已发布题卷快照隔离
- 面试评分明细查看、误评分重置
- 按管理员、HR、领导、面试官划分后台权限
- SQLite 数据库在线备份下载
- 人才库按姓名、手机号、岗位和审核状态筛选
- 人才详情展示真实评分维度与完整审核历史
- 顶部候选人搜索与按角色动态显示菜单
- 应聘码、面试码展示、打印与 PNG 下载
- 完整 15 项任职资料采集、评分版本及岗位快照
- 岗位基本素质维度和权重配置
- 面试场次状态、人员明细、二维码轮换与成员移除
- 面试评分草稿、正式提交锁定和管理端重置
- 人才库独立检索页及面试结果 CSV 导出
- CSV 模板下载、文件批量导入
- 系统基础参数、用户启停和登录/验证限频
- Session Cookie HttpOnly、SameSite 与 HTTPS Secure 适配
- 管理端与 H5 全局大字号、放大按钮和表格可读性优化
- 岗位、题目、用户等新增编辑表单统一弹窗交互
- 角色、题型、规则、审核动作和操作日志中文化
- 面试官采用固定七维评分表（1–5 分制及固定权重）
- 固定评分表包含综合评价、录用建议、薪资与到岗日期

## 本地运行

在 PowerShell 中执行：

```powershell
.\start.ps1
```

然后打开 `http://127.0.0.1:8080/index.php`。

- 管理员账号：`admin`
- 初始密码：`admin123`
- 演示应聘者手机号：`13800138000`（已提交状态）
- 演示面试官：`李四`、`王五`

首次访问会自动创建 `data/app.db` 并写入演示数据。生产部署前请修改初始密码、关闭错误显示并启用 HTTPS。

## 备份

管理员可在“操作日志”页面下载在线备份，也可以定时执行：

```powershell
.\backup.ps1
```

备份文件保存在 `data/backups/`。

## 上线检查

- Web 根目录只能指向 `public/`，禁止直接暴露 `data/`、`app/` 和 `migrations/`。
- 使用 HTTPS；生产环境关闭 `display_errors`，并设置数据库目录仅由 PHP 运行用户读写。
- 首次登录后立即修改 `admin` 初始密码，并为 HR、领导和面试官建立独立账号。
- 将二维码中的 `127.0.0.1` 替换为手机可访问的正式域名后再打印。
- 使用系统任务计划每日执行 `backup.ps1`，并定期把备份复制到其他设备。
