# 任职管理系统

PHP 8.1+ 与 SQLite 实现，管理端采用 A「深海行政」视觉风格，包含岗位、预登记、人才审核、面试安排以及应聘/面试 H5 流程。

- 综合测评结构化评分标准及版本发布
- 通用题库、岗位专业题库与题卷版本发布
- 应聘者预登记及 CSV 导出
- 手机号与岗位双重验证、在线答题和自动计分

- 面试场次、候选人和多面试官配置
- 面试官姓名验证、独立评分和防重复提交

- 数据驱动的在线题卷与题目快照
- 单选、多选客观题自动判分
- 简答题人工评分与综合分重新计算
- 文本批量预登记（姓名、手机号逐行导入）

- 多面试官权重汇总及面试结果页

- 题目启停与已发布题卷快照隔离
- 面试评分明细查看、误评分重置
- 按管理员、HR、领导、面试官划分后台权限
- SQLite 数据库在线备份下载
- 人才库按姓名、手机号、岗位和审核状态筛选

## 本地运行

在 PowerShell 中执行：

```powershell
.\start.ps1
```

然后打开 `http://127.0.0.1:8080/index.php`。

- 管理员账号：`admin`
- 初始密码：`admin123`
- 演示应聘者手机号：`13800138000`（已提交状态）
- 演示面试官：`李四`、`王五`

首次访问会自动创建 `data/app.db` 并写入演示数据。生产部署前请修改初始密码、关闭错误显示并启用 HTTPS。

## 面试实操

- 管理员或 HR 在「面试管理」创建场次并安排应聘者，再到「题目管理 → 实操题目」搜索并选择岗位，维护 1–30 道题。同岗位场次共用题库，新增默认启用；新增和编辑使用大文本弹窗，支持停用及删除。
- 应聘者直接访问 `/practical.php`，不需要后台账号；填写登记的姓名和手机号后，进入已安排且开放的场次。存在多个场次时先选择场次。
- 每题独立选择一份成果，可附说明；多份材料可打包为 ZIP。可逐题上传保存，也可选好全部文件后直接确认提交，系统自动逐题上传并在全部成功后提交。失败时保留已保存成果并允许重试；已上传题目可单独更新说明，无需重传文件。提交后不能修改。场次结束、取消或移除人员后，不能继续进入作答。停用全部题目后不再允许新答卷，已有答卷仍可继续。
- 开始作答时保存题目快照；后续编辑、停用或删除题目不改变已有答卷和成果。在「面试结果」点击对应应聘者的「实操成果」，按题查看和下载该人本场文件。只有实操作答、尚无面试评分的记录也会显示；题目维护页不再混放成果。
- 文件类型：PDF、DOC/DOCX、XLS/XLSX、PPT/PPTX、TXT、CSV、ZIP；图片 JPG/JPEG、PNG、GIF、WebP、HEIC；视频 MP4、MOV、M4V、WebM、MKV、AVI。应用上限为单文件 500 MB，页面实际显示 PHP `upload_max_filesize` 与 `post_max_size` 允许的较小上限。上传时显示传输百分比及已传输大小。
- 本地 `php.ini` 配置为 `upload_max_filesize=500M`、`post_max_size=512M`、`max_input_time=1800`，修改后需重启 PHP。线上发布时也需同步调整 PHP 和 Web 服务器/反向代理的请求大小与超时限制；只更新应用代码不会放宽服务器限制。
- 成果保存在数据库同级的 `practical-files` 私有目录，文件名随机且不保留可执行扩展名，仅通过鉴权下载。可用环境变量 `PRACTICAL_STORAGE_DIR` 指定位于网站公开目录之外的持久目录；部署时需确保 PHP 进程可写。**备份时应同时备份 SQLite 数据库和该成果目录**，数据库备份下载不包含成果文件。
- 回归验证：`node tests/practical-flow.cjs`（需 Playwright / Edge）；使用临时副本，不修改业务数据。

## 备份

管理员可在“操作日志”页面下载在线备份，也可以定时执行：

```powershell
.\backup.ps1
```

备份文件保存在 `data/backups/`。

## 上线检查

- Web 根目录只能指向 `public/`，禁止直接暴露 `data/`、`app/` 和 `migrations/`。
- 使用 HTTPS；生产环境关闭 `display_errors`，并设置数据库目录仅由 PHP 运行用户读写。
- 首次登录后立即修改 `admin` 初始密码，并为 HR、领导和面试官建立独立账号。
- 将二维码中的 `127.0.0.1` 替换为手机可访问的正式域名后再打印。
- 使用系统任务计划每日执行 `backup.ps1`，并定期把备份复制到其他设备。
